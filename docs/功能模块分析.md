# Mall 电商后台管理系统 功能模块分析

> 被测系统：macrozheng/mall（Spring Boot 3.x 后端 + mall-admin-web Vue3 管理后台）
> 分析方式：登录系统实际操作逐一浏览各模块页面，结合后端接口与前端源码交叉核对
> 分析日期：2026-09-07
> 环境：本地部署（后端 http://localhost:8080，前端 http://localhost:5173）
> 登录账号：admin / macro123（超级管理员）

---

## 1. 系统概述

| 项目 | 说明 |
|---|---|
| 后端 | mall-admin（Spring Boot，接口前缀无 /admin，如 `/product/list`、`/order/list`） |
| 前端 | mall-admin-web（Vue3 + Element Plus，Hash 路由 `#/xxx`） |
| 数据层 | MySQL 库 `mall` + Redis（缓存） |
| 认证方式 | 登录接口返回 JWT token，请求头 `Authorization: Bearer <token>` |
| 权限模型 | 用户（ums_admin）→ 角色（ums_role）→ 菜单（ums_menu）+ 资源（ums_resource，后端接口权限） |

**后台菜单共 5 大模块**：首页、商品、订单、营销、权限（另有"学习教程/视频教程"外链菜单，非业务功能）。

各模块对应后端接口前缀（来自权限-资源列表，如 `/product/**`、`/order/**`、`/brand/**` 等）：

| 模块 | 前端路由前缀 | 后端接口前缀（示例） |
|---|---|---|
| 商品 | /pms | /product/**、/productCategory/**、/productAttribute/**、/brand/**、/sku/** |
| 订单 | /oms | /order/**、/orderSetting/**、/returnApply/**、/returnReason/** |
| 营销 | /sms | /sms/flash/**、/coupon/**、/home/**、/advertise/** |
| 权限 | /ums | /admin/**（用户）、/role/**、/menu/**、/resource/** |

## 3. 商品模块（/pms）

**定位**：商品全生命周期管理（分类 → 类型/属性 → 品牌 → 商品 CRUD + 上下架/推荐/库存）。

### 3.1 商品列表（路由 /pms/product）

> ⚠️ **实际操作发现异常（缺陷候选）**：点击左侧菜单"商品列表"或直接访问 `#/pms/product`，页面渲染内容错误——本次会话显示为"添加商品"页（填写商品信息/促销/属性/关联四步表单），此前会话显示为"商品分类"列表页；无法正常查看商品列表。
> 交叉验证：后端接口 `GET /product/list?pageNum=1&pageSize=3` 正常返回 200，共 **20 条商品**（如"华为 HUAWEI P20"），说明后端与数据均正常，**问题定位在前端路由/页面渲染层**（vue-router 动态路由匹配异常，页面组件与路由未正确对应）。已实测：菜单点击、直接 hash 访问、刷新页面后均复现。

按前端源码（`src/views/pms/product/index.vue`）整理的设计功能：

- 筛选条件：商品编号/名称、商品分类（两级级联选择）、品牌、上架状态（上架/下架）、审核状态（审核通过/未审核）
- 批量操作：商品上架、商品下架、设为推荐、取消推荐、设为新品、取消新品、移入回收站、转移到分类
- 单条操作：查看详情、编辑、删除、上架/下架切换、SKU 库存弹窗编辑（按商品 ID 查询/更新 SKU 库存）
- 列表字段（设计）：编号、商品名称、图片、价格、库存、上下架状态等

| ③ 填写商品属性 | 按商品类型加载属性/参数 |
| ④ 选择商品关联 | 关联商品、专题、优选等 |

**测试关注点**：必填项校验、价格/库存数值边界、分类-类型-属性联动、四步数据回显与提交。

### 3.3 商品分类（路由 /pms/productCate）

- 页面元素：列表 + "添加"按钮；操作列含"查看下级 / 转移商品 / 编辑 / 删除"

**商品模块测试重点**：商品 CRUD 全流程、分类树（查看下级/转移商品）、类型-属性参数配置、品牌管理；接口 `/product/**`、`/productCategory/**`、`/productAttribute/**`、`/brand/**`、`/sku/**`。

## 4. 订单模块（/oms）

**定位**：订单查询处理、订单规则设置、退货售后管理。

### 4.1 订单列表（路由 /oms/order）

- 筛选条件：输入搜索（订单编号）、收货人、提交时间、订单状态（全部/待付款/待发货/已发货/已完成等）、订单分类（全部）、订单来源（全部）
- 操作按钮：查询搜索、重置
- 列表字段：编号、订单编号、提交时间、用户账号、订单金额、支付方式、订单来源、订单状态、操作
- 实测数据：后端 `GET /order/list` 共 **48 条**订单（如订单号 201809150101000001、用户 test、金额 ￥18732）；前端列表正常展示
- 隐藏页面（源码）：订单详情（/oms/orderDetail）、发货列表（/oms/deliverOrderList）

### 4.2 订单设置（路由 /oms/orderSetting）

- 表单项（实测）：**秒杀订单超过 ___ 分钟未付款，订单自动关闭**；**正常订单超过 ___ 分钟未付款，订单自动关闭**
- 对应后端接口 `/orderSetting/**`，超时分钟数为可配置值

### 4.3 退货申请处理（路由 /oms/returnApply）

- 筛选条件：输入搜索、处理状态（全部/待处理/已处理等）、申请时间
- 操作：查询搜索、重置；操作列含"确认收货"相关处理
- 对应接口 `/returnApply/**`；隐藏页面：退货申请详情

### 4.4 退货原因设置（路由 /oms/returnReason）

- 页面元素：列表 + "添加"按钮
- 列表字段：编号、原因类型、排序
- 对应接口 `/returnReason/**`

**订单模块测试重点**：订单多条件组合查询、分页；订单状态流转（付款→发货→收货→完成/关闭）；超时自动关闭规则；退货申请处理与原因配置。

## 5. 营销模块（/sms）

**定位**：促销活动与首页运营位配置（秒杀、优惠券、推荐位、广告）。

- 筛选：活动名称

- 列表字段：编号、活动标题、活动状态（进行中/已结束）、开始时间、结束时间、上线/下线
- 实测数据：共 **1 条**："双11特卖活动"（2022-11-09 至 2023-12-31，状态"活动已结束"）
- 隐藏页面：秒杀时间段列表、时间段选择、秒杀商品关联

### 5.2 优惠券列表（路由 /sms/coupon）

- 筛选：优惠券名称、优惠券类型（全部/满减券/赠券等）

### 5.3 品牌推荐（路由 /sms/brand）

- 筛选：品牌名称、推荐状态（全部/推荐中）

- 列表字段：编号、品牌名称、是否推荐、排序、状态、操作
- 实测数据：小米、华为、苹果、海澜之家、OPPO、三星、万和、方太、格力 等 9 条

### 5.4 新品推荐（路由 /sms/new）

- 筛选：商品名称、推荐状态

### 5.5 人气推荐（路由 /sms/hot）

- 实测数据：共 **5 条**：iPad 10.9、小米 Book Pro 14、三星 980 SSD、万和燃气热水器、OPPO Reno8

### 5.6 专题推荐（路由 /sms/subject）

- 筛选：专题名称、推荐状态；操作：选择专题、设置排序、删除
- 实测数据：共 **6 条**：夏季精选、polo衬衫的也时尚、大牌手机低价秒、晓龙845新品上市、夏天应该穿什么、品牌手机降价

- 筛选：广告名称、广告位置（全部/APP首页轮播等）、到期时间
- 操作：添加广告；单条：编辑、删除；列表含上线/下线开关
- 列表字段：编号、广告名称、广告位置、广告图片、时间（开始/到期）、上线/下线、点击次数、生成订单、操作
- 实测数据：电影推荐广告、汽车促销广告、汽车推荐广告、夏季大热促销 等（位置多为"APP首页轮播"）

## 6. 权限模块（/ums）

- 列表字段：编号、帐号、姓名、邮箱、添加时间、最后登录、是否启用、操作

## 9. 下一步测试建议（简要）

1. **商品模块**：优先排查 BUG-001（可作为作品集"缺陷分析"亮点案例：定位到前端路由层，后端接口与数据正常）；商品 CRUD、分类-类型-属性联动、SKU 库存为重点功能测试对象。
2. **订单模块**：订单多条件筛选、状态流转、超时自动关闭规则配置与验证。
3. **权限模块**：RBAC 授权链路测试（不同角色登录 → 菜单可见性 → 接口 401/403），接口鉴权用 `/product/**`、`/order/**` 等资源路径做越权验证。
4. **接口测试基础**：以 `/admin/login` 获取 token → 带 `Authorization` 调业务接口，可先对 `/product/list`、`/order/list`、`/brand/list` 等建立接口用例基线。
